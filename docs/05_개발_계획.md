## 3. 시험 전략

- **계약 시험**: `schema/fixtures`를 TS와 Kotlin이 함께 읽어 같은 판정을 내는지 확인합니다. 스키마를 바꾸면 `npm run schema`로 fixture를 다시 만듭니다.
- **상태 머신**: 서버 전이(`transition`)와 차량 리듀서(`CarHandoffMachine`)를 순수 함수로 두고 표 형태로 시험합니다.
- **실행 환경 시험**: 중계 서버는 workerd(`@cloudflare/vitest-pool-workers`)에서 짧은 유효시간으로 만료·묘비 삭제까지 실제 시간으로 확인합니다.
- **E2E**: 브라우저(가짜 차량)와 에뮬레이터(실제 차량 앱 + Chrome 휴대폰)로 흐름 전체를 돌리고, 화면을 `docs/evidence/`에 남깁니다.
