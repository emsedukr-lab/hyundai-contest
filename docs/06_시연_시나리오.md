# 06 시연 시나리오 (2차 PT, 5~7분)

## 준비

| 항목 | 내용 |
|---|---|
| 차량 | Pleos Connect Emulator 2.1.0, cold boot, 떠날지도 prod APK, 기어 P |
| 휴대폰 | 실제 스마트폰 1대(기본 카메라) + 예비 1대(재사용 거부 시연용) |
| 서버 | 배포된 Worker (예비: staging) |
| 네트워크 | 행사장 Wi-Fi + 휴대폰 핫스팟 예비 |
| 사전 데이터 | 휴대폰에 '강릉 3박 4일' 샘플 여행, 차량은 여행 0개 |
| 예비 자료 | 전체 흐름 녹화 영상 `media/demo/떠날지도_시연.mp4`(1분 56초), `docs/evidence` 화면 |
| 에뮬레이터 | `-gpu host`로 cold boot (소프트웨어 렌더링이면 시스템 화면이 멈춤). 내비 안내가 남아 있으면 '안내 종료' |

## 장애 대응

| 상황 | 대응 |
|---|---|
| 행사장 네트워크 불안정 | 핫스팟으로 전환. 차량은 "연결 다시 시도 중" 표시 후 이어짐 |
| 폰 스캐너가 fragment를 버림 | 기본 카메라로 다시 스캔 (화면이 안내함) |
| QR 시간 초과 | [새 QR 받기] — 그 자체를 만료 복구 시연으로 사용 |
| 내비가 확정 응답을 늦게 줌 | "내비 화면에서 경로를 확인해 주세요" 안내 후 최대 30초 대기, 실패 시 [내비에서 찾기] |
| 서버 장애 | staging 서버 APK로 교체, 최후에는 녹화 영상 |
| 주행 상태 전환 불가 (VHAL 미연결) | 시연 모드의 주행 스위치를 쓰고 "시연 스위치"라고 밝힘 |

## 정직하게 밝힐 범위

- 실차와 실제 주행 중 사용성은 검증하지 못했습니다. 에뮬레이터와 Mac 화면 기준입니다.
- 샘플 장소 좌표는 시연용 근사값이고, 이동시간과 영업시간은 사용자가 입력한 값만 씁니다.
- 지속 동기화는 구현하지 않았습니다(설계만 있음).
